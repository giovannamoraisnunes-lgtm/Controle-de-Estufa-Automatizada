Objetivos do Projeto & Equipe

Objetivo Geral

Desenvolver uma solução acessível de automação agrícola e botânica, unindo interface web interativa em tempo real (via Firebase Realtime Database) a um sistema de controle físico microcontrolado (ESP32) para garantir o desenvolvimento ideal de cultivos.

Especificações e Desenvolvimento do Projeto

Detalhamento técnico, arquitetura de hardware, software em nuvem Firebase e etapas de engenharia.

1. Especificações de Hardware

  • Microcontrolador ESP32: Núcleo Tensilica Dual-Core com Wi-Fi para envio de dados ao Firebase Realtime Database.
  • Sensor DHT22: Alta precisão na medição de temperatura e umidade relativa do ar.
  • Sensor de Solo e LDR: Monitoramento de umidade da terra e luxes luminosos.
  • Módulo Relé de 4 Canais: Acionamento de bomba, exaustor, luz Grow e nebulizador.

2. Arquitetura Firebase Realtime Database

  • Armazenamento em Nuvem: O ESP32 envia dados JSON em tempo real para o nó `/estufa`.
  • Sincronização Reativa: O site consome os dados instantaneamente via SDK web do Firebase (`onValue`).

3. Metodologia de Desenvolvimento

  1. Pesquisa e Modelagem: Definição das faixas ideais de cultivo.
  2. Prototipagem de Circuitos: Testes em protoboard com ESP32 e sensores.
  3. Desenvolvimento Firmware & Nuvem: Programação C++ integrando a biblioteca FirebaseESP32.
  4. Integração Web Final: Conexão do dashboard com o banco de dados em tempo real.

Código C++ (ESP32 + Firebase)

Código para envio de dados ao Firebase.

#include <WiFi.h>
#include <FirebaseESP32.h>
#include <DHT.h>

#define WIFI_SSID "ELIZABETH"
#define WIFI_PASSWORD "29011953"

#define DATABASE_URL "estufaautomatizada-40380-default-rtdb.firebaseio.com"
#define DATABASE_SECRET "SEU_SEGREDO"

#define DHTPIN 4
#define DHTTYPE DHT22
#define PIN_SOLO 34
#define PIN_LDR 35

DHT dht(DHTPIN, DHTTYPE);
FirebaseData fbdo;
FirebaseAuth auth;
FirebaseConfig config;

void setup() {
  Serial.begin(115200);
  dht.begin();
  
  WiFi.begin(WIFI_SSID, WIFI_PASSWORD);
  while (WiFi.status() != WL_CONNECTED) {
    delay(500);
    Serial.print(".");
  }

  config.database_url = DATABASE_URL;
  config.signer.test_mode = true;
  Firebase.begin(&config, &auth);
  Firebase.reconnectWiFi(true);
}

void loop() {
  float temp = dht.readTemperature();
  float umid = dht.readHumidity();
  int solo = map(analogRead(PIN_SOLO), 4095, 1500, 0, 100);
  int lux = map(analogRead(PIN_LDR), 0, 4095, 0, 2000);

  if (Firebase.ready()) {
    Firebase.setFloat(fbdo, "/estufa/temperatura", temp);
    Firebase.setFloat(fbdo, "/estufa/umidade", umid);
    Firebase.setInt(fbdo, "/estufa/umidSolo", solo);
    Firebase.setInt(fbdo, "/estufa/lux", lux);
  }

  delay(2000);
}
