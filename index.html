Objetivos do Projeto & Equipe

Objetivo do Controle Remoto

Permitir a intervenção e o acionamento remoto de atuadores (Bomba de irrigação, Ventoinha e Fita de LED) diretamente da interface web para o ESP32 em tempo real, além da leitura contínua dos sensores (DHT11, LDR, umidade do solo e boia).

Painel de Controle Manual dos Atuadores

Clique nos botões abaixo para acionar ou desligar os componentes do ESP32 remotamente através do Firebase.

Bomba d'Água

Acionamento Irrigação (`in3` - GPIO 19)

DESLIGADA

Liga a bomba de água para irrigação. *A boia bloqueia automaticamente se o reservatório estiver vazio.*

Ventoinha / Exaustor

Circulação de Ar (`in1` - GPIO 5)

DESLIGADA

Aciona a ventoinha para controle de temperatura ou exaustão de umidade do ar.

Fita de LED

Iluminação Suplementar (`in2` - GPIO 18)

DESLIGADA

Liga a iluminação auxiliar para fotossíntese de plantas em locais com baixa luz natural.

Especificações do Sistema Manual

Arquitetura de envio de comandos web e sensores.

1. Controle em Tempo Real

O site se comunica com o caminho /estufa/atuadores/ no Firebase Realtime Database. Quando um botão é pressionado no navegador, a variável booleana muda para true ou false e o ESP32 atualiza os pinos digitais instantaneamente.

2. Trava de Segurança da Boia

Mesmo com o comando de LIGAR enviado pela web, a bomba d'água (`in3`) só funcionará fisicamente se a boia de nível (`boia` - GPIO 4) detectar água no reservatório, prevenindo danos ao motor.

Configuração do Firebase

Insira o link do seu projeto do Firebase Realtime Database.

Código C++ para ESP32 (Controle Manual)

Copie e grave no seu ESP32 via Arduino IDE.

#include <FirebaseESP32.h>
#include <WiFi.h>
#include <DHT.h>

const char* ssid = "STM_ULISSES_5G";
const char* password = "30241146";

#define FIREBASE_HOST "estufaautomatizada-40380-default-rtdb.firebaseio.com"
#define FIREBASE_AUTH ""

FirebaseData firebaseData;
FirebaseConfig firebaseConfig;
FirebaseAuth firebaseAuth;

const int boia = 4;         
const int in1 = 5;          // Ventoinha
const int capacitivo = 34;    
const int dht11 = 21;         
const int ledVerde = 2;       
const int ledVermelho = 15;   
const int in2 = 18;           // Fita LED
const int in3 = 19;           // Bomba
const int ldr = 35;           

DHT dht(dht11, DHT11);

void setup() {
  Serial.begin(115200);

  pinMode(boia, INPUT_PULLUP);
  pinMode(capacitivo, INPUT);
  pinMode(ldr, INPUT);
  pinMode(in1, OUTPUT);
  pinMode(ledVerde, OUTPUT);
  pinMode(ledVermelho, OUTPUT);
  pinMode(in2, OUTPUT);
  pinMode(in3, OUTPUT);

  dht.begin();
  analogReadResolution(12);

  WiFi.begin(ssid, password);
  while (WiFi.status() != WL_CONNECTED) {
    delay(500);
    Serial.print(".");
  }

  firebaseConfig.host = FIREBASE_HOST;
  firebaseConfig.signer.test_mode = true;
  Firebase.begin(&firebaseConfig, &firebaseAuth);
  Firebase.reconnectWiFi(true);
}

void loop() {
  // 1. Leituras Físicas
  const bool reservatorioCheio = (digitalRead(boia) == LOW);
  const int leituraBrutaSolo = analogRead(capacitivo);
  int percentagemumidade = map(leituraBrutaSolo, 3000, 1200, 0, 100);
  percentagemumidade = constrain(percentagemumidade, 0, 100);

  const float umidadeAr = dht.readHumidity();
  const float temperatura = dht.readTemperature();
  const int valorLDR = analogRead(ldr);

  // 2. Leitura dos Comandos Manuais do Firebase
  if (WiFi.status() == WL_CONNECTED) {
    // Leitura do estado dos Atuadores enviados do Site
    if (Firebase.getBool(firebaseData, "/estufa/atuadores/bomba")) {
      bool estadoBombaCmd = firebaseData.boolData();
      // Segurança: Liga a bomba se o comando for TRUE e a boia indicar reservatório cheio
      digitalWrite(in3, (estadoBombaCmd && reservatorioCheio) ? HIGH : LOW);
    }

    if (Firebase.getBool(firebaseData, "/estufa/atuadores/ventoinha")) {
      bool estadoVentoinhaCmd = firebaseData.boolData();
      digitalWrite(in1, estadoVentoinhaCmd ? HIGH : LOW);
    }

    if (Firebase.getBool(firebaseData, "/estufa/atuadores/led")) {
      bool estadoLedCmd = firebaseData.boolData();
      digitalWrite(in2, estadoLedCmd ? HIGH : LOW);
    }

    // Sinalização por LED Físico
    if (!reservatorioCheio) {
      digitalWrite(ledVermelho, HIGH);
      digitalWrite(ledVerde, LOW);
    } else {
      digitalWrite(ledVerde, HIGH);
      digitalWrite(ledVermelho, LOW);
    }

    // Envio dos Dados de Telemetria para o Firebase
    Firebase.setFloat(firebaseData, "/estufa/temperatura", temperatura);
    Firebase.setFloat(firebaseData, "/estufa/umidadeAr", umidadeAr);
    Firebase.setInt(firebaseData, "/estufa/umidadeSolo", percentagemumidade);
    Firebase.setInt(firebaseData, "/estufa/luminosidade", valorLDR);
    Firebase.setBool(firebaseData, "/estufa/reservatorioCheio", reservatorioCheio);
  }

  delay(2000);
}
