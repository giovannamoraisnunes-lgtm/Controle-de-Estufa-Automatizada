Objetivos do Projeto & Equipe

Objetivo Geral

Desenvolver uma solução acessível de automação agrícola e botânica, unindo interface web interativa em tempo real a um sistema de controle físico microcontrolado (ESP32) para garantir o desenvolvimento ideal de cultivos sob rigorosos padrões de temperatura, umidade e luminosidade.

Especificações e Desenvolvimento do Projeto

Detalhamento técnico, arquitetura de hardware, software e etapas de engenharia desenvolvidas pela equipe.

1. Especificações de Hardware

  • Microcontrolador ESP32: Núcleo Tensilica Dual-Core de 32 bits com Wi-Fi e Bluetooth integrados para transmissão de telemetria sem fio.
  • Sensor DHT22: Alta precisão na medição de temperatura (-40 a 80°C) e umidade relativa do ar (0 a 100%).
  • Sensor de Umidade do Solo: Eletrodos analógicos para detecção volumétrica de umidade na terra.
  • Sensor LDR: Fotorresistor conectado a divisor de tensão para monitoramento de luxes (luminosidade).
  • Módulo Relé de 4 Canais: Isolamento por optoacopladores para acionamento seguro de cargas (bomba de irrigação, exaustor, lâmpadas Grow e nebulizador).

2. Arquitetura de Software & Web

  • Interface Web Responsiva: Desenvolvida em HTML5 com estilização moderna via Tailwind CSS e componentes dinâmicos.
  • Gráficos Dinâmicos: Biblioteca Chart.js para visualização em tempo real de tendências climáticas.
  • Web Serial API: Comunicação nativa bidirecional via USB sem necessidade de softwares intermediários.
  • Protocolo MQTT: Conexão lightweight para controle e monitoramento remoto via nuvem.

3. Metodologia de Desenvolvimento

O projeto foi concebido em ciclos iterativos de engenharia, divididos em quatro fases principais pela equipe colaborativa:

  1. Pesquisa e Modelagem: Levantamento dos requisitos botânicos e definição das faixas ideais de cultivo para cada parâmetro ambiental.
  2. Prototipagem de Circuitos: Montagem física em protoboard, testes de calibração dos sensores analógicos/digitais e teste do módulo de relés.
  3. Desenvolvimento Firmware & Interface: Programação em C++ (Arduino IDE) para o ESP32 e criação simultânea da interface web SPA (Single Page Application).
  4. Integração e Testes Finais: Validação cruzada entre a telemetria física via Serial/MQTT e os algoritmos de controle automático de atuadores.

Código C++ Gerado para ESP32

Copie e cole este código diretamente na Arduino IDE.

#include <WiFi.h>
#include <PubSubClient.h>
#include <DHT.h>

// Pinos
#define DHTPIN 4
#define DHTTYPE DHT22
#define PIN_SOLO 34
#define PIN_LDR 35

#define RELE_BOMBA 26
#define RELE_EXAUSTOR 27
#define RELE_LUZ 14
#define RELE_NEBULIZADOR 12

DHT dht(DHTPIN, DHTTYPE);

void setup() {
  Serial.begin(115200);
  dht.begin();
  
  pinMode(RELE_BOMBA, OUTPUT);
  pinMode(RELE_EXAUSTOR, OUTPUT);
  pinMode(RELE_LUZ, OUTPUT);
  pinMode(RELE_NEBULIZADOR, OUTPUT);
}

void loop() {
  float temp = dht.readTemperature();
  float umidAr = dht.readHumidity();
  int soloRaw = analogRead(PIN_SOLO);
  int soloPercent = map(soloRaw, 4095, 1500, 0, 100);
  int ldrRaw = analogRead(PIN_LDR);
  int lux = map(ldrRaw, 0, 4095, 0, 2000);

  // Envia JSON pela Serial
  Serial.print("{\"temp\":"); Serial.print(temp);
  Serial.print(",\"umidAr\":"); Serial.print(umidAr);
  Serial.print(",\"umidSolo\":"); Serial.print(soloPercent);
  Serial.print(",\"lux\":"); Serial.print(lux);
  Serial.println("}");

  delay(2000);
}
