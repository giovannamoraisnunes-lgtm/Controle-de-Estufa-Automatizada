Objetivos do Projeto & Equipe

Objetivo Geral e Botânico

Desenvolver uma solução autônoma baseada em ESP32 para gerenciamento térmico, hídrico e lumínico voltada à otimização do cultivo de suculentas. O sistema integra sensores de alta precisão, controle preventivo de nível de reservatório via boia e sincronização em nuvem via Firebase.

Especificações e Detalhes de Desenvolvimento

Fundamentação técnica, lógica de controle para suculentas e arquitetura de hardware implementada no ESP32.

1. Requisitos Botânicos (Suculentas)

O projeto foi dimensionado especificamente para as exigências fisiológicas de suculentas, que necessitam de solos bem drenados e evitam umidade excessiva nas raízes:

  • Solo Seco (< 20%): Dispara o acionamento da bomba d'água (`in3`), condicionado estritamente à verificação da boia de nível.
  • Solo Muito Úmido (> 60%): Risco de apodrecimento. Desliga a irrigação e aciona a ventoinha (`in1`) para aeração.
  • Temperatura/Umidade do Ar: Caso ultrapasse 32°C ou 70% de umidade relativa, o sistema liga preventivamente a ventoinha para resfriamento e troca gasosa.

2. Arquitetura de Hardware & Sensores

  • Sensor DHT11 (GPIO 21): Monitoramento digital integrado da temperatura e umidade do ar.
  • Sensor Capacitivo de Solo (GPIO 34): Leitura analógica com conversão ADC de 12 bits (0 a 4095), mapeada entre o ponto seco (3000) e úmido (1200).
  • Sensor LDR (GPIO 35): Monitoramento contínuo da luz ambiente. Valores abaixo de 1800 acionam a fita de LED (`in2`) para suplementação luminosa.
  • Sensor de Boia (GPIO 4): Chave de nível com pull-up interno. Impede o funcionamento a seco da bomba de irrigação.

3. Integração com Nuvem (Firebase)

O ESP32 conecta-se à rede Wi-Fi local e utiliza a biblioteca `FirebaseESP32` para persistir dados estruturados em tempo real no banco de dados Firebase Realtime Database sob o caminho raiz `/estufa/`:

  • /estufa/temperatura (Float)
  • /estufa/umidadeAr (Float)
  • /estufa/umidadeSolo (Int)
  • /estufa/luminosidade (Int)
  • /estufa/reservatorioCheio (Boolean)

Segurança e Sinalização Visual

O sistema possui sinalização física por LEDs (Verde para estado normal/adequado e Vermelho para alertas críticos de temperatura, umidade ou falta de água no reservatório), garantindo confiabilidade operacional autônoma.

Ativada se umidade do solo < 20% **E** sensor de boia (GPIO 4) indicar reservatório cheio (LOW).

Ativada se temperatura > 32°C, umidade do ar > 70% ou umidade do solo > 60%.

Ativada automaticamente se a leitura analógica do LDR for inferior a 1800.

Código C++ Atualizado para ESP32

Código oficial do projeto com suporte a DHT11 e Firebase.

#include <FirebaseESP32.h>
#include <WiFi.h>
#include <DHT.h>
#include <esp32/rom/ets_sys.h>
#include <esp32-hal.h>

const char* ssid = "STM_ULISSES_5G";
const char* password = "30241146";

#define FIREBASE_HOST "estufaautomatizada-40380-default-rtdb.firebaseio.com"
#define FIREBASE_AUTH ""

FirebaseData firebaseData;
FirebaseConfig firebaseConfig;
FirebaseAuth firebaseAuth;

const int boia = 4;         
const int in1 = 5;          
const int capacitivo = 34;    
const int dht11 = 21;         
const int ledVerde = 2;       
const int ledVermelho = 15;   
const int in2 = 18;           
const int in3 = 19;           
const int ldr = 35;           

DHT dht(dht11, DHT11);

void setup() {
  Serial.begin(115200);

  pinMode(boia, INPUT_PULLUP);
  pinMode(capacitivo, INPUT);
  pinMode(ldr, INPUT);
  pinMode(in1, OUTPUT);
  pinMode(ledVerde, OUTPUT);
  pinMode(ledVermelho, OUTPUT);
  pinMode(in2, OUTPUT);
  pinMode(in3, OUTPUT);

  dht.begin();
  analogReadResolution(12);

  WiFi.begin(ssid, password);
  while (WiFi.status() != WL_CONNECTED) {
    delay(500);
    Serial.print(".");
  }

  firebaseConfig.host = FIREBASE_HOST;
  firebaseConfig.signer.test_mode = true;
  Firebase.begin(&firebaseConfig, &firebaseAuth);
  Firebase.reconnectWiFi(true);
}

void loop() {
  const int estadoBoia = digitalRead(boia);
  const bool reservatorioCheio = (estadoBoia == LOW);

  const int valorSeco = 3000;
  const int valorumido = 1200;
  const int leituraBruta = analogRead(capacitivo);

  int percentagemumidade = map(leituraBruta, valorSeco, valorumido, 0, 100);
  percentagemumidade = constrain(percentagemumidade, 0, 100);

  if (percentagemumidade < 20) {
    digitalWrite(in3, reservatorioCheio ? HIGH : LOW);
    digitalWrite(ledVermelho, HIGH);
  } else if (percentagemumidade > 60) {
    digitalWrite(in3, LOW);
    digitalWrite(in1, HIGH);
    digitalWrite(ledVermelho, HIGH);
  } else {
    digitalWrite(in3, LOW);
    digitalWrite(ledVerde, HIGH);
  }

  const float umidadeAr = dht.readHumidity();
  const float temperatura = dht.readTemperature();

  if (!isnan(umidadeAr) && !isnan(temperatura)) {
    if (temperatura > 32.0 || umidadeAr > 70.0) {
      digitalWrite(in1, HIGH);
      digitalWrite(ledVermelho, HIGH);
    } else {
      digitalWrite(in1, LOW);
      digitalWrite(ledVerde, HIGH);
    }
  }

  const int valorLDR = analogRead(ldr);
  if (valorLDR < 1800) {
    digitalWrite(in2, HIGH);
  } else {
    digitalWrite(in2, LOW);
  }

  if (WiFi.status() == WL_CONNECTED) {
    Firebase.setFloat(firebaseData, "/estufa/temperatura", temperatura);
    Firebase.setFloat(firebaseData, "/estufa/umidadeAr", umidadeAr);
    Firebase.setInt(firebaseData, "/estufa/umidadeSolo", percentagemumidade);
    Firebase.setInt(firebaseData, "/estufa/luminosidade", valorLDR);
    Firebase.setBool(firebaseData, "/estufa/reservatorioCheio", reservatorioCheio);
  }

  delay(5000);
}
